# marvinoka4 projects

This is the public showcase for my projects: **https://marvinoka4.github.io**

Each project has its own page. It covers what the project is, what it does, how it works at a high level, the results so far and who it is for.

- **Open source** projects link straight to their code on GitHub.
- **Private** projects keep their code in a private repository. Use the "Request access" button on the project page, or email info@marvinoka4.com, to ask for access or a licence.

Each page also links to a longer case study on my portfolio.

## What is in this repository

Only the website itself: page templates, styles, and a short description and images for each project. No project code lives here. Project pages are kept up to date automatically from each project's own repository.

The site is built by GitHub Pages with Jekyll. It uses no tracking or analytics scripts.
